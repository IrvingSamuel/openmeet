# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Reporting a vulnerability

Do **not** open a public issue for security problems.

Email the maintainers with:

- A short description of the issue
- Steps to reproduce (or a proof of concept)
- Impact assessment if known

We aim to acknowledge reports within a few business days and coordinate a fix before any public disclosure.

## Scope

In scope: authentication, authorization, room access control, secret handling, dependency CVEs that affect this repository.

Out of scope: denial-of-service against public demo instances, social engineering, issues that require physical access to a self-hosted server.
